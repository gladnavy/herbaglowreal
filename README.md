# HerbaGlow website

Static website for HerbaGlow — Nature Beauty Care.

- `index.html` — the whole site (shop, scalp quiz, ingredients, results, cart and checkout)
- `img/` — product photos, sets, herbs, customer results, logo
- `media/` — product film (MP4) and its poster image

To publish free on GitHub Pages: Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.

Note: checkout is a front-end preview. Orders are not sent anywhere yet; a payment provider or Shopify is needed to take real orders.
